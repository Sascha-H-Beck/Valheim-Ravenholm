# OdinsVision

**Version:** 0.0.4  
**Release date:** 2025-03-08  
**Status:** Alpha

## About

OdinsVision adds a red-vision effect that highlights living, non-player characters in Valheim.

## Installation (manual)

Install BepInEx, then copy `OdinsVision.dll` into your Valheim `BepInEx/plugins` folder.

## How to activate

Press `F8` in-game to toggle red vision on or off. You can change the shortcut with the `ToggleVisionKey` setting in the BepInEx configuration.
